# Programmieren 1 – Assignment Woche 4

Die Aufgaben werden in der **JShell** bearbeitet. Da die JShell keine `.java`-Dateien speichert, soll pro Aufgabe der Quelltext der Sitzung in die vorbereitete Datei im Ordner `aufgaben/` gespeichert (`aufgabe1.txt`, `aufgabe2.txt`, ...) werden.

## Quelltext speichern

1. JShell starten: `jshell`. Idealerweise laden Sie dazu diese Repository als Ordner herunter und öffnen die JShell in dem Repo-Ordner.
2. Aufgabe bearbeiten. Falsche Eingaben mit `/drop <name>` entfernen oder die Aufgabe sauber neu durchlaufen lassen.
3. Mit `/list` prüfen, dass nur die gewünschten Snippets aktiv sind.
4. Speichern:

   ```
   /save aufgaben/aufgabe1.txt
   ```
   Bitte beachten Sie dazu, dass die Dateien bereits existieren müssen und die JShell im richtigen Pfad geöffnet sein muss.
   
   Falls die Aufgabe mehrere Teilaufgaben mit unterschiedlichem Code enthält, fügen Sie beide Versionen ein und kennzeichnen Sie diese mit einem Kommentar.

5. JShell mit `/exit` beenden.

Vor jeder neuen Aufgabe mit `/reset` den Zustand zurücksetzen, damit keine Snippets aus anderen Aufgaben in der Datei landen. Ob die Datei vollständig ist, lässt sich mit `/reset` und anschließendem `/open aufgaben/aufgabe1.txt` prüfen.

## Abgabe

Die Abgabe erfolgt automatisch über Classroom50. Bewertet wird die letzte auf GitHub hochgeladene Version. 

Sie dürfen zum Hochladen den Web-Editor auf GitHub benutzen. Falls Sie bereits Erfahrung mit Git/GitHub haben, dürfen Sie auch selbstständig den Code pushen.

> [!IMPORTANT]  
> Achten Sie insbesondere darauf, dass sie in **Ihrer eigenen Repository** sind. Dies erkennen Sie daran, dass der Name der Repository Ihren Nutzernamen enthält.

Nicht hochgeladener Quellcode kann nicht bewertet werden.
